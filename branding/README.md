## Typography

| Use | Font |
|-----|------|
| Wordmark ("SignalSort") | **Segoe UI Bold** |
| Tagline and UI body | **Segoe UI** (regular) |
| UI icon glyphs | **Segoe MDL2 Assets** / **Segoe Fluent Icons** (system icon font) |

Segoe UI ships with Windows — it does not need to be installed, and the font
file itself is not redistributed with this project (its license only permits
distribution as part of Windows).

**Free alternative for non-Windows rendering:** [Selawik](https://github.com/microsoft/Selawik)
(SIL OFL) — Microsoft's open-source, metric-compatible Segoe UI replacement.
Use it anywhere Segoe UI is unavailable (Linux/macOS mockups, web previews).
